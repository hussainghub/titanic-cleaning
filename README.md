# Titanic Passenger survival analysis.
This project is a data cleaning and exploratory pipeline for the titanic dataset.
## Tools used 
            - Python Numpy  
            - Pandas 
            - Matplotlib tools.
## Data Cleaning Workflow
            - Handled the missing values in the "Age" column using the median
            - Removed incomplete records in the "Embarked" column.
## How to Run 
            - clone the repo
            - install dependencies: pip install pandas matplotlib
            - run the script: python titanic.py
## Result
            - dataset dimensions
            - survival rate by passenger class
            - count of missing values per column 
            - missing values are embarked and ages are filled in the titanic.csv file
